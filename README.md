# 文化空间联动排期台

本服务用于跨场地节目线路、共享资源和变更通知。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：节目版本、场地时窗、共享资源、转场约束、审批、线路、观众批次、通知。

正式锁定前同时校验全部时窗和资源；规则快照随发布保存；突发关闭只生成候选调整；候选经人工确认后才能替换线路。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/cultural_schedule.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
